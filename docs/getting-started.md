# Getting Started

## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Node.js 20+](https://nodejs.org/) (for Explorer UI development)
- Git (for SDK parity tests)

## Quick Start

### Run from source

```bash
# Clone the repository
git clone https://github.com/your-org/azure-light-cosmos-emulator.git
cd azure-light-cosmos-emulator

# Build everything
dotnet build

# Run the emulator
dotnet run --project src/Cli -- start
```

### Run via Docker

```bash
docker compose -f docker/docker-compose.yml up
```

### Install as global tool

```bash
dotnet pack src/Cli -c Release
dotnet tool install --global --add-source src/Cli/nupkg cosmos-emulator

cosmos-emulator start
```

## Connect with SDK

```csharp
using Microsoft.Azure.Cosmos;

var client = new CosmosClient(
    "https://localhost:8081",
    "<master-key>",
    new CosmosClientOptions
    {
        ConnectionMode = ConnectionMode.Gateway,
        HttpClientFactory = () => new HttpClient(
            new HttpClientHandler { ServerCertificateCustomValidationCallback = (_, _, _, _) => true })
    });

var database = await client.CreateDatabaseIfNotExistsAsync("mydb");
var container = await database.Database.CreateContainerIfNotExistsAsync("mycoll", "/partitionKey");
```

## CLI Commands

| Command | Description |
|---|---|
| `cosmos-emulator start` | Start the emulator |
| `cosmos-emulator stop` | Stop a running background instance |
| `cosmos-emulator reset` | Wipe all data |
| `cosmos-emulator status` | Show running status and endpoints |
| `cosmos-emulator export --output data.json` | Export all data |
| `cosmos-emulator import --input data.json` | Import data |

## Configuration

The emulator can be configured via:
- CLI options (`--port`, `--data-dir`, etc.)
- `appsettings.json`
- Environment variables (e.g., `Emulator__Port=8081`)

See `src/Host/Configuration/EmulatorOptions.cs` for all options.
